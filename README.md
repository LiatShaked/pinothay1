# מפת פינות החי בישראל

מפה אינטראקטיבית של פינות חי, חוות חינוכיות וטיפוליות במוסדות חינוך בישראל, מחולקת לפי יישובים.

🔗 האתר החי: https://liatshaked.github.io/pinothay1/

## קבצים
רק קובץ אחד נדרש: `index.html`
גבולות היישובים נטענים ישירות מול שירות ArcGIS הרשמי, אין צורך בקובץ geojson נפרד.

## שמירת נתונים
הנתונים נשמרים ב-Firebase (מסד נתונים משותף), כך שהם מוצגים לכל מי שנכנס לאתר, לא רק בדפדפן שבו הוזנו.

## עריכה
רק משתמשת מחוברת (דרך תיבת "כניסת מנהלת" בתחתית התפריט) יכולה להוסיף, לערוך או למחוק פינות חי. כולם יכולים לצפות, לחפש, ולייצא ל-JSON/Excel.

## חשוב - העברת נתונים ישנים
אם יש רשומות שנשמרו בגרסה קודמת (בדפדפן מקומי, localStorage) - יש לייצא אותן משם (⬇️ ייצוא JSON או 📊 ייצוא Excel) ואז לייבא אותן כאן דרך הכפתורים המתאימים לאחר התחברות כמנהלת.
